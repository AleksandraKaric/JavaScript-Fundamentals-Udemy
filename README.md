# JavaScript Fundamentals - Udemy

This project contains JavaScript fundamentals exercises as preparation for working with Playwright for end-to-end testing.

## 📚 Topics Covered

- Variables (`let`, `const`)
- Data types (strings, numbers, booleans)
- Console output
- Conditional statements (`if`, `else`)
- Functions
- Loops
- Arrays and objects
- Basic DOM manipulation (optional, later)

## 💻 Tools Used

- Visual Studio Code
- Node.js
- Git & GitHub

## 🚀 How to Run

To run any example, open the terminal and type:

```bash
node filename.js
Replace filename.js with the actual file name (e.g., 01-variables.js).

🔖 Purpose
This repository is used for learning and practicing JavaScript basics with a focus on test automation preparation.
